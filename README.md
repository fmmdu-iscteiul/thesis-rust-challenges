# thesis-rust-challenges
This repository contains all five challenges related to the thesis **Serious Game-Based Security Training for Rust Developers**

## File directory
The folder _individual_challenges_ contains:
- Challenge 1: Packet Handling
- Challenge 2: Sandbox Breach

As for the _storyline_challenges_ folder:
- Challenge 3: Input Validation
- Challenge 4: Improper Handling
- Challenge 5: Combined Vulnerabilities

Each challenge contains 3 folders, a README.md, and, for storyline challenges, a context.txt:
- **completion_artifacts**: files released upon challenge completion
- **src**: files presented to the learner at the start of the challenge
- **tests**: custom tests that run on challenge validation
- **README.md**: The challenge onboarding file for the learner
- **context.txt** [storyline only]: file containing a more detailed description of the issue
